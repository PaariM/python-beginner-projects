# python-beginner-projects

Three small console projects written in plain Python while learning the basics.
No external libraries are needed, only Python 3.8 or newer.

| # | Project | What it does | Concepts used |
|---|---------|--------------|---------------|
| 1 | [Student Marks Analyzer](1_student_marks_analyzer.py) | Stores student marks in a CSV file; shows total, average, grade, topper and pass percentage | Lists, dictionaries, functions, CSV, exception handling |
| 2 | [Expense Tracker](2_expense_tracker.py) | Adds, views and deletes expenses; shows total and category-wise spending | OOP (classes), JSON, dictionaries, datetime |
| 3 | [Text Analyzer](3_text_analyzer.py) | Counts words, lines and characters; finds the longest and most frequent words; checks palindromes | Strings, dictionaries, sets, file handling |

## How to run

```bash
python 1_student_marks_analyzer.py
python 2_expense_tracker.py
python 3_text_analyzer.py
```

For project 3, put your own text in a file named `sample.txt` next to the script,
or type the text when asked.
